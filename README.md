Resolución del ejercicio N°1 de la unidad 1 de programación 2.
El programa realiza el calculo del total de una estadía para una empresa de alquiler online.
Para realizar el calculo pide la cantidad de noches que estuvo el huésped y el precio por noche.
Luego de realizar el calculo, devuelve un informe sobre el precio final y los datos del huésped.
